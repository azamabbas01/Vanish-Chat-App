# Vanish Class Network

Android chat application adapted to the class-wide **Vanish Relay Protocol v1**.

For setup, open [`VANISH_GUIDE.md`](VANISH_GUIDE.md). The full agreed message contract is in [`PROTOCOL.md`](PROTOCOL.md).

The `server/` directory is the original HTTP field-sync teaching starter. It is not the hosted WebSocket relay used by this class chat. Do not run it as a replacement for the shared relay.
